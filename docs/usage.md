# 操作ガイド

| キー | 操作 |
|---|---|
| `Tab` / `Shift+Tab` | ペイン切替 |
| `1` / `2` / `3` | 板・スレ・レスペインへ |
| `j` / `k`、矢印 | 選択を移動 |
| `Enter` | 板・スレを開く、参照を表示 |
| `Space` / `PageDown`、`PageUp` | 5件ずつ移動 |
| `Home` / `End`・`G` | 先頭・末尾（レスでは最新本文の末尾） |
| `Ctrl+↑` / `Ctrl+↓` | 長い本文を1行ずつスクロール |
| `/`、`Esc` | 検索、検索解除 |
| `u` | 板・スレURLを開く |
| `f` | お気に入りを切替 |
| `v` | 板→お気に入り→履歴→ログの切替 |
| `s` / `c` / `U` / `d` | 勢い・レス数・未読・作成順（同じキーで昇降順反転） |
| `p` | 同じ板で次スレ候補を検索 |
| `n` / `g` | 未読境界・レス番号へ |
| `a` / `i` / `t` | 参照・同じID・被返信レス |
| `L` | 保存済みログの全文検索 |
| `r` | 選択ペインを更新 |
| `A` / `F` / `I` | 自動更新＋新着追従・追従のみ・更新間隔 |
| `N` | NG設定 |
| `W` / `T` / `z` | 折り返し・配色・自動→3ペイン→上下表示→1ペイン切替 |
| `[` / `]` / `x` | タブ移動・タブを閉じる |
| `o` / `b` | リンク・スレをブラウザで開く |
| `B` | アプリ内のスレ立て画面を開く |
| `w` / `R` | 返信下書き・選択レスへの引用下書き |
| `e` | スレをTXT・JSONへ書き出し |
| `?` / `F1` | ヘルプ |
| `q` / `Ctrl+C` | 終了 |

NG入力例:

```text
id:abcdefgh
name:ﾜｯﾁｮｲ XXX
body:非表示にしたい文字列
title:除外したいスレタイ
body:/正規表現/
id@60:abcdefgh
clear
```

`@60` は60分後に失効する指定です。`clear` はすべてのNGを解除します。

板一覧とスレ一覧の境界を左右にドラッグすると板の幅を、スレ一覧とレスの境界を左右にドラッグするとスレ一覧の幅を変更できます。上部タブ欄の下線を上下にドラッグするとタブ欄の高さを変更できます。上下表示（`two`）では、左に板一覧、右上にスレ一覧、右下にレスを表示します。スレ一覧とレスの境界を上下にドラッグすると高さを調整できます。スレタイトルの固定表示も維持します。マウスを離した時点で保存し、次回起動時に復元します。端末が小さい場合は各ペインが表示できるサイズに制限されます。

## マウス・カテゴリ・お気に入り

各ペインの右上にある「更新」をクリックすると、板一覧・スレ一覧・レスをそれぞれ手動更新できます。キーボードの `r` と同じ操作です。

板一覧はカテゴリの階層表示です。クリックまたは `Enter` で開閉、`→` で展開、`←` で折りたたみます。板をクリックするとスレ一覧、スレをクリックするとレスを開きます。スクロールした位置に合わせてクリックできます。`/` の検索中は該当する板を表示します。

板を選択して `f`、または板を右クリックするとお気に入りを切り替えます。先頭の「お気に入り」フォルダ内で、板をドラッグまたは `Ctrl+↑/↓` で並べ替えます。並び順とフォルダの開閉状態は保存します。

スレ一覧の上にある「レス・未読・勢い・日時」はクリックで並べ替えます。キーボードでは `c`・`U`・`s`・`d`。作成日時は日本時間の `月/日 時:分` で表示し、並べ替えは年・秒も含む元の時刻で比較します。同じ項目を再度選ぶと昇順・降順が反転します。更新後も選択した並べ替えを適用します。

レス欄の「最新へ」ボタン、またはレスペインで `End` / `G` を押すと最新レスの本文末尾へ移動します。右端のスクロールバーはクリック・ドラッグで移動できます。ホイールは本文を3行ずつスクロールし、手動スクロールすると新着追従を解除します。

レス欄上部の「A 自動」をクリック、または `A` で自動更新と新着追従をまとめて切り替えます。新着時はレス末尾へスクロールします。「F 追従」または `F` は追従のみ切り替えます。手動で読み戻すと追従は解除されます。更新間隔は「I 秒数」または `I`（最小10秒）。オフラインでは自動更新できません。

## 外部板を追加

エッヂは板一覧の「エッヂ」カテゴリから開けます。`u` に `https://bbs.eddibb.cc/liveedge/` やスレURLを入力しても開けます。

したらばは `u` に `https://jbbs.shitaraba.net/カテゴリ/板番号/` または `/bbs/read.cgi/カテゴリ/板番号/スレ番号/` 形式のURLを入力してください。板・スレのどちらから開いても板一覧に保存します。初回の板取得時に板名を取得し、お気に入りには通常の板と同じ操作で登録できます。全したらば掲示板の一覧取得には対応していません。

外部板も検索・NG・自動更新・新着追従・ログ保存を共通で使えます。エッヂ・したらばの返信・スレ立ては未対応です。送信操作では下書きを保存して未対応と表示し、通信は行いません。

## 書き込み・スレ立て（5ch・TUI内）

返信とスレ立ては端末内で入力・確認・送信します。別ウィンドウやWebView2は使いません。

- 返信: `w`（引用は `R`）で本文を入力。
- スレ立て: 投稿する板を選択して `B`。タイトルを確定して本文を入力。
- 編集中: `F2` 名前、`F3` メール、`F4` スレタイトル。`Esc` で下書きを保存して閉じる。
- 送信: `F6` または `Ctrl+Enter` で内容を確認し、`Enter` で送信。
- サーバーの確認画面: 上下キーで読む、`Tab` でボタン選択、`1`〜`9` で選択フォームのチェック項目を切り替え、`Enter` で続行。`v` でHTMLソース表示、`Esc` で編集に戻る。

名前・メール・下書き・CookieはSQLiteに保存します。成功応答を認識すると本文をクリアし、スレと板を更新します。通信失敗時の自動再送はしません。投稿済みかスレを更新して確認してください。デモ・オフラインでは送信しません。

HTTPの投稿フォームと確認フォームに対応します。確認ページはテキスト表示で、HTMLソースも読めます。JavaScript実行、画像認証、ブラウザによるログインは未対応です。サーバーがこれらを要求する場合、CLIだけで完了できません。5ch本番での投稿・スレ立て成功は未検証です。

実行時に必要なバイナリは `tui5ch.exe` のみです。


## スレタブとペイン

上部の `1:タイトル`・`2:タイトル` は開いているスレのタブ番号です。IMEを英数入力にして `[`・`]` で切り替え、`x` で現在のタブを閉じます。タブのクリック切り替えは未対応です。数字キー `1`・`2`・`3` は板・スレ・レスのペイン選択です。
